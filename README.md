\# BudgetBuddy – Personal Budget Planning and Expense Management Platform



BudgetBuddy is a full-stack personal finance management platform designed to help users manage their income, expenses, budgets, savings goals, notifications, and financial reports from a single application.



\## 🚀 Live Application



\*\*Frontend:\*\*  

https://budget-buddy-a-full-stack-personal-kohl.vercel.app/



\*\*Backend API:\*\*  

https://budget-buddy-finance-tracker-yo7z.onrender.com/



\## ✨ Features



\- User registration and authentication

\- JWT-based login

\- Income management

\- Expense management

\- Budget management

\- Savings goal tracking

\- Notifications

\- Financial reports

\- Dashboard and analytics

\- Responsive frontend

\- Production deployment



\## 🛠️ Technology Stack



\### Frontend

\### Backend

\### Deployment

\- Backend: Render
